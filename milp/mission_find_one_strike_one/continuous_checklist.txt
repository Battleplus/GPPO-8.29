连续性检查清单（新版：发现一个→打击一个 循环流程）

═══════════════════════════════════════════════════════════════
设计原则
═══════════════════════════════════════════════════════════════

原则 1：发现即打击（Find-One Strike-One）
  每次只确认一个目标，确认后立即在下一帧打击，打完再移动 AOI 找下一个。

原则 2：AOI 对准目标所在格
  commander_AOI 的格子编号直接对应目标的坐标格，UAV 不会在无目标的区域徘徊。

原则 3：目标仅在 AOI 覆盖时才能被确认
  当 commander_AOI 不包含某目标的格子，该目标必须保持 confirmed=false。

原则 4：目标格子映射规则（坐标空间约 0-300，5×5 格网，每格 60 单位）
  col = ceil(x / 60)，row = ceil(y / 60)
  g1 [252, 238] → col=5, row=4 → A_4_5
  g2 [ 72, 221] → col=2, row=4 → A_4_2
  g3 [232-238, 74-77]（MISSION_04-05 时段）→ col=4, row=2 → A_2_4
  g4 [ 57-53, 132-137]（MISSION_06-07 时段）→ col=1, row=3 → A_3_1

═══════════════════════════════════════════════════════════════
快照目标状态与 AOI 对应关系
═══════════════════════════════════════════════════════════════

MISSION_00：UAV 部署，AOI=A_4_5（g1 所在格），4 个目标全部 confirmed=false。
MISSION_01：UAV 检查 A_4_5，g1 落在 AOI 内 → g1 confirmed=true。
             g2/g3/g4 不在当前 AOI，继续 confirmed=false。
MISSION_02：g1 打击完成，从 targets 中移除。
             AOI 移至 A_4_2（g2 所在格），g2/g3/g4 仍 confirmed=false。
MISSION_03：UAV 检查 A_4_2，g2 落在 AOI 内 → g2 confirmed=true。
             g3/g4 不在当前 AOI，继续 confirmed=false。
MISSION_04：g2 打击完成，从 targets 中移除。
             AOI 移至 A_2_4（g3 当前预测所在格），g3/g4 仍 confirmed=false。
MISSION_05：UAV 检查 A_2_4，g3 落在 AOI 内 → g3 confirmed=true。
             g4 不在当前 AOI，继续 confirmed=false。
MISSION_06：g3 打击完成，从 targets 中移除。
             AOI 移至 A_3_1（g4 当前预测所在格），g4 仍 confirmed=false。
MISSION_07：UAV 检查 A_3_1，g4 落在 AOI 内 → g4 confirmed=true。
MISSION_08：g4 打击完成，targets 为空，任务终止保持帧。

═══════════════════════════════════════════════════════════════
字段检查
═══════════════════════════════════════════════════════════════

- 所有 JSON 顶层字段：scenario_name、aoi、staging_position、commander_AOI、
  grid_weather、platforms、targets。
- RADAR 和 CP 不含 velocity、pos_cov。
- AV 含 velocity、pos_cov。
- confirmed=true 当且仅当该目标的坐标格包含在 commander_AOI 中。
- targets 仅在目标被明确打击的帧中减少，被打击目标在下一帧移除。
- MISSION_07 和 MISSION_08 之间 g4 被打击，MISSION_08 的 targets 为空数组。
- MISSION_08 的 commander_AOI 为空数组 []，表示任务结束无需继续侦察。
- 所有 JSON 均可被 json.loads() 直接解析。
