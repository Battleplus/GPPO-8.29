# 两模型 Minimum-Validation 与极端多事件压力测试结论

## 1. 总体结论

本项目已完成 PPO-MLP 与 GPPO-Adaptive 的 minimum-validation 合同对齐、正式训练证据封存、固定 50k checkpoint 评估，以及面向多任务变化、多事件并发、突发事件、临时变更和信息不完整的探索性极端压力测试。

现有证据不支持“GPPO-Adaptive 在所有场景全面优于 PPO-MLP”。更准确的结论是：

> GPPO-Adaptive 是强关系耦合和资源争用场景下具有研究价值的候选策略；PPO-MLP 仍是固定小规模任务图、持续事件风暴和严格实时约束下更稳定、更高效的基线。

因此，后续研究重点不应是简单增加训练步数，而应转向“场景识别、规划兜底、历史记忆与新隐藏测试集验证”。

## 2. 已完成的证据闭环

正式 minimum-validation 合同已经统一为：

- 模型：PPO-MLP、GPPO-Adaptive；
- 训练 seeds：`1101`、`2202`、`3303`；
- 预算：每个 run `50,000 steps`；
- checkpoints：`25,000`、`50,000`；
- 正式训练：6/6 runs，共 `300,000 steps`；
- checkpoint：12/12，25k 与 50k 各 6 个；
- 正式评估：固定使用 6 个 50k checkpoint，不进行 checkpoint selection；
- held-out：100 cases，五个场景各 20 cases。

训练、checkpoint SHA-256、source/protocol/seed-manifest provenance 和评估证据均已封存。极端压力测试没有重新训练模型，也没有修改正式 minimum-validation、旧 campaign 或固定评估结果。

探索性压力测试包括 7 类场景、42 条固定 paired tapes 和 420 个完整回合。全部 420 个回合正常结束，reward invariant 全部通过，没有 invalid action 或 repaired action。

## 3. 正式评估结论

正式 100-case 评估中，两种模型的总体成功率、合法覆盖率和 episode return 接近，没有形成稳定的总体胜负。

- PPO-MLP 的归一化距离更低，平均推理时延约 `2.51 ms`，在实时性和执行成本方面更有优势。
- GPPO-Adaptive 的平均推理时延约 `17.07 ms`，计算代价明显更高。
- GPPO-Adaptive 在 Sequential、Overlap 和 Burst 中出现部分回报正向趋势，但只有三个独立训练 seeds，证据不足以支持普遍优越性声明。
- Test-Unseen 没有证明图结构编码能够自动解决分布外变化、信息延迟或部分可观测问题。

正式评估说明：当前 GPPO 的主要价值不是全面提高成功率，而可能是改善部分高耦合状态下的资源协调质量。

## 4. 极端场景结论

### 4.1 GPPO 最有价值的场景

在 `tracking_saturation_release` 场景中，三架 UAV 进入 TRACK、最后一架搜索 UAV 损毁，并需要等待未来目标销毁释放资源。GPPO 相对 PPO 的三个训练 seed 均表现出一致方向：

- 平均恢复延迟减少约 `0.678`；
- 平均累计空缺减少约 `12.817`；
- 平均 episode return 增加约 `0.610`。

这说明当任务之间存在明确关系、资源被长期占用且未来释放事件决定后续调度时，图策略能够利用关系结构改善恢复过程。

相应代价是归一化距离增加约 `0.024`，推理时延增加约 `12.37 ms`。Current-Pending Exact Planner 在该场景的恢复延迟和累计空缺还略优于 GPPO，因此小规模在线规划器具有现实的兜底价值。

### 4.2 PPO 更合适的场景

在 `event_storm_8` 持续事件风暴中，GPPO 相对 PPO：

- 恢复延迟增加约 `0.014`；
- 累计空缺增加约 `0.555`；
- 归一化距离增加约 `0.0367`；
- 负载差增加约 `0.1305`；
- episode return 降低约 `0.186`；
- 推理时延增加约 `11.59 ms`。

在 `task_churn` 快速任务反复变更中，GPPO 也没有形成稳定优势。由此可见，“事件更多”不等于“图模型一定更好”；当前两层局部消息传递不足以处理长事件链和快速状态反转。

### 4.3 信息不完整场景

在 `out_of_order_reports` 因果报告乱序场景中，两种前馈模型基本打平。当前模型没有事件历史、信息年龄、报告置信度或 belief state，因此图编码器本身不能解决乱序、延迟和缺失信息。

旧决策竞争审计已经证明：当事件在推理完成后、动作提交前到达时，graph/action version 机制能够拒绝旧动作，不错误消耗 reward 或 decision step，并允许基于新图重新决策。这解决的是执行一致性问题，不等于模型已经具备信息不完整条件下的推理能力。

### 4.4 指标解释边界

所有方法在 42 条 tapes 上最终均达到 100% 事件成功率和 100% 合法覆盖率。这主要来自 action mask、合法性约束和环境恢复机制，说明成功率在当前环境中已经接近天花板。

后续不能只用成功率或 episode return 评价策略，应同时报告：

- 累计空缺；
- 恢复延迟；
- 归一化距离；
- 负载差；
- P95/P99 推理与端到端决策时延；
- 尾部失败风险和不可行率。

## 5. 场景化选型建议

| 应用场景 | 当前优先方法 | 原因与边界 |
|---|---|---|
| 固定小图、严格实时、事件持续到达 | PPO-MLP | 推理快、距离低、稳定性较好 |
| 搜索/跟踪资源争用、等待未来资源释放 | GPPO-Adaptive | 恢复更快、累计空缺更少，但需接受更高时延 |
| 小规模、安全关键、必须可审计 | Exact Planner | 决策可解释，可作为 GPPO/PPO 的在线兜底 |
| 高频任务取消、重开和临时变更 | PPO 或 Greedy Cost | 当前 GPPO 未体现稳定收益 |
| 报告乱序、延迟、缺失和长时间盲区 | 当前两模型均不足 | 需要循环记忆、belief state 或显式状态估计 |
| 动态规模或未知拓扑 | 尚无充分结论 | 当前实验仅覆盖固定 4 UAV、4 Region、3 Target |

## 6. 项目当前的研究定位

项目已经从“能否完成两模型训练和复现实验”推进到“什么状态结构值得使用图策略”的阶段。当前最有依据的研究命题是：

> 在资源占用关系强、任务存在竞争并且未来释放事件影响当前决策时，关系感知策略可能比普通 MLP 更有效；但在固定小图、短视决策已经足够或时延约束严格时，PPO 和轻量规划方法更实用。

当前仍存在四个主要缺口：

1. 图规模固定，尚未验证节点数量和拓扑变化下的泛化能力；
2. 两个策略均为前馈结构，没有真正处理部分可观测性；
3. reward 与累计空缺等业务指标不总是同向；
4. 当前极端场景是在观察正式结果后设计的开发集，不能作为新的正式 held-out 结论。

## 7. 下一阶段建议

建议在新的独立研究分支中依次验证：

1. **Beam-MPC / Rolling-Horizon Planner**：规划未来 3–5 个决策步，每层保留 8–16 个候选，显式考虑未来资源释放和任务变化；
2. **Planner-Distilled MLP**：以规划器产生专家动作，通过行为克隆和 DAgger 蒸馏，争取接近规划质量并保持 PPO 级推理速度；
3. **Recurrent QR-DQN / R2D2**：引入历史记忆和回报分布，处理乱序、延迟、缺失信息及尾部风险；
4. **策略路由器**：普通状态使用 PPO，高关系耦合状态切换至 GPPO，安全关键状态由规划器复核或兜底。

本次 42 条极端 tapes 只能作为开发集。算法、指标和阈值冻结后，应重新生成未见过的 `Extreme-V2` hidden bank，并执行一次性评估。建议最低验收目标为：

- 最终事件成功率 100%；
- 最终不可行率为 0；
- 累计空缺相对 PPO 降低至少 10%；
- 恢复延迟降低至少 5%；
- 距离与负载恶化均不超过 5%；
- 满足预先规定的端到端 P95 时延上限。

## 8. 最终结论

PPO-MLP 是当前系统中速度快、实现成熟、适用于常规动态调度的可靠基线。GPPO-Adaptive 没有表现出全面优势，但在搜索/跟踪资源强争用和等待未来资源释放的特殊状态中显示出稳定的恢复收益。

下一步最合理的路线不是用 GPPO 替换 PPO，而是研究“PPO 常规执行、GPPO 处理强耦合状态、在线规划器负责安全兜底”的组合体系，并通过新的隐藏极端场景验证其真实泛化能力。

---

**证据边界：** 本文中的正式结论来自固定 50k checkpoint 的 minimum-validation；极端场景结果属于 post-hoc exploratory development evidence，不用于 checkpoint selection，也不应被描述为新的正式 held-out test。
