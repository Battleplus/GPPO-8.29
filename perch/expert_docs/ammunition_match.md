# 弹药目标匹配与阵位区域

## 静止目标

- 固定工事优先考虑激光制导导弹，区域需支持稳定悬停、地形遮蔽和照射通视。
- 固定车辆和火炮优先考虑反坦克导弹，区域需支持合适俯角并兼顾遮蔽与距离。
- 指挥所或通信站应优先考虑防区外攻击，距离安全优先级高于近距离通视。

## 移动目标

- 装甲纵队宜使用毫米波雷达或红外制导武器，区域宜位于目标运动方向侧前方。
- 与目标移动方向夹角 30-60 度通常较合适，攻击扇面应覆盖可能机动范围。
- 轻型车辆可使用火箭弹或机炮，区域需要支持快速进入和退出。

## 区域尺度

- 激光制导弹药的候选区域通常位于目标 2-5km 范围内，并受照射通视约束。
- 雷达制导弹药的候选区域可扩展至 3-8km。
- 火箭弹候选区域通常位于目标 1-5km 范围内，优选 2-4km；机炮候选区域通常位于 0.5-2km，优选 0.8-1.5km。
- 具体距离必须以任务输入中的实际武器最小、最大和最佳射程为准。
