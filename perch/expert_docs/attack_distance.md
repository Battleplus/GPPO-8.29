# 攻击距离约束

## 导弹类武器

- 反坦克导弹有效射程通常为 2-8km，最佳攻击距离为 3-5km。
- AGM-114 激光制导型有效射程约 0.5-8km，最佳攻击距离为 3-6km。
- AKD-10 有效射程约 1-7km，最佳攻击距离为 2-5km。
- 距离过近会增加被探测和近程防空威胁，超过有效射程则无法完成打击。

## 火箭弹与机炮

- 火箭弹有效射程约 1-5km，最佳攻击距离为 2-4km，远距离散布误差明显增加。
- 机枪和机炮有效射程约 0.5-2km，最佳攻击距离为 0.8-1.5km，应重点利用地形遮蔽。

## 生存与引导约束

- 攻击距离增加通常有助于降低被发现概率，但必须受当前武器包线约束。
- 距离达到 6km 左右时，敌方近程防空系统威胁通常显著降低。
- 地面激光照射组通常位于距目标 1-3km 处，攻击阵位需要兼顾照射通视。
- 照射组至目标连线与攻击方向夹角不宜超过 45 度。
